# Code of Conduct

This project aims to be a safe, constructive space for everyone.

## Expected behavior

- Communicate respectfully, patiently, and constructively
- Focus on the topic instead of the person when disagreements happen
- Give feedback clearly and professionally
- Make room for people with different experience levels and perspectives

## Unacceptable behavior

- Insults, harassment, discrimination, or belittling language
- Personal attacks, threats, or trolling
- Sharing private information without permission
- Repeated behavior intended to derail discussion

## Enforcement

Project maintainers may enforce these rules across issues, comments, and pull requests. When necessary, they may warn participants, hide comments, lock discussions, or restrict further participation.

## Reporting

If you see behavior that harms the community, contact the maintainers privately. For security-related reports, use [SECURITY.md](./SECURITY.md).
