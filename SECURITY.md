# Security policy

Do not report security vulnerabilities through public issues.

## How to report

If you find a security problem, share it privately with the repository owner, including technical details, impact, and reproduction steps when possible. If you do not yet have a private contact method configured for the repository, add one before publishing the project and update this file.

## What to expect

- Reports are reviewed and validated first.
- A fix is prepared based on the impact and scope of the issue.
- Details should stay private until the issue is resolved.

There is no formal supported-version matrix yet; the expectation is that reports target the latest `main` branch or the latest packaged release.
