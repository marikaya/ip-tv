# Contributing

Thanks for contributing to Deneme IPTV. Before opening a contribution, follow the short workflow below.

## Before you start

- Check existing issues and pull requests first; someone may already be working on the same topic.
- If you plan a larger change, open an issue first so the approach can be discussed.
- Do not report security issues in public issues; use the process described in [SECURITY.md](./SECURITY.md).

## Development setup

```bash
npm install
npm run dev
```

Before submitting changes:

```bash
npm run check
```

## Contribution expectations

- Keep changes small and focused.
- Follow the existing code style and naming patterns.
- Update the README when user-facing behavior changes.
- For bug fixes, explain how the issue can be reproduced in the issue or PR description.

## Pull request flow

1. Create your branch from an up-to-date `main`.
2. Prepare your changes as clear, focused commits.
3. Explain what changed and why in the PR description.
4. Add screenshots or short validation steps when relevant.

All contributors are expected to communicate respectfully and follow the [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md).
